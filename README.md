# Network Information

| Field         | Value              |
|---------------|--------------------|
| **MAC Address** | `XX:XX:XX:XX:XX:XX` |
| **IP Address**  | `192.168.X.X`      |
| **Device Name**  | `your-device-name` |
| **Date**         | `2026-08-07`       |

---

## Apna MAC / IP Address Kaise Nikalein

### Windows
```
ipconfig /all
```
- **IPv4 Address** wahan aapka IP hai
- **Physical Address** wahan aapka MAC hai

### Mac / Linux
```
ifconfig
```
ya

```
ip addr show
```
