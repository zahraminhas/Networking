
# Networking Class 01 - Basics

## 1. Introduction to Networking

### Definition

A computer network is a group of two or more computers and devices connected to each other to share data, information, and resources.

### Explanation

Networking ka matlab hai do ya do se zyada computers ya devices ko aapas mein connect karna, taake woh data aur information share kar saken.

**Example:** Jab hum mobile ko Wi-Fi ke saath connect karte hain, to mobile network ka hissa ban jata hai.

### Uses of Networking

- Data aur files share karna.
- Internet use karna.
- Printers aur doosre devices share karna.
- Email aur messages send karna.
- Online classes aur meetings attend karna.

## 2. What Is a Computer Network?

Computer network aise connected devices ka group hota hai jo aapas mein communication karte hain.

### Main Components of a Network

1. **Sender:** Jo data send karta hai.
2. **Receiver:** Jo data receive karta hai.
3. **Transmission Medium:** Woh raasta jis se data travel karta hai, jaise cable ya Wi-Fi.
4. **Network Devices:** Router aur switch jaise devices.
5. **Protocols:** Communication ke rules jin par devices amal karte hain.

### Example

Jab aap WhatsApp par kisi ko message send karte hain, to aapka mobile data send karta hai aur doosre shakhs ka mobile data receive karta hai.

## 3. What Is a Router?

### Definition

A router is a networking device that connects different networks and forwards data packets between them.

### Explanation

Router aik networking device hai jo different networks ko connect karta hai. Yeh data ko uski destination tak pohanchane ke liye munasib route select karta hai.

### Functions of a Router

- Different networks ko connect karna.
- Data packets ko sahi destination ki taraf forward karna.
- Home network ko internet se connect karna.
- Wi-Fi ke zariye wireless connection provide karna, agar router wireless ho.
- Network traffic ko manage karna.

### Example

Ghar mein Wi-Fi router mobile aur laptop ko internet provide karta hai.

### Router and Switch Difference

| Router | Switch |
|---|---|
| Different networks ko connect karta hai. | Aik local network mein devices ko connect karta hai. |
| IP address ki madad se routing karta hai. | Aam tor par MAC address ki madad se frames forward karta hai. |
| Internet connection share karne mein madad karta hai. | Local devices ke darmiyan communication karwata hai. |

## 4. What Is an IP Address?

### Definition

An IP address is a logical address assigned to a device on an IP network for identification and communication.

### Explanation

IP address aik logical address hota hai jo network par device ko identify karne aur data ko sahi destination tak pohanchane mein madad karta hai.

Jaise ghar ka address kisi ghar ko identify karta hai, isi tarah IP address network par device tak data pohanchane mein madad karta hai.

### Types of IP Addresses

#### 1. IPv4

IPv4 aik IP addressing system hai jo 32-bit address use karta hai.

**Example:** `192.168.1.1`

IPv4 address mein four numbers hote hain jo dots se separate hote hain.

#### 2. IPv6

IPv6 aik IP addressing system hai jo 128-bit address use karta hai. Isay IPv4 ke muqable mein bohat zyada addresses provide karne ke liye banaya gaya hai.

**Example:** `2001:db8::1`

### Public IP Address

Public IP address internet par network ko identify karne ke liye use hota hai. Yeh aam tor par Internet Service Provider (ISP) provide karta hai.

### Private IP Address

Private IP address local network ke andar devices ko identify karne ke liye use hota hai.

**Example:** `192.168.1.10`

### Static IP Address

Static IP address woh hota hai jo manually ya network configuration ke zariye fixed rakha jata hai.

### Dynamic IP Address

Dynamic IP address automatically assign hota hai, aam tor par DHCP server ke zariye.

## 5. What Is LAN?

### Definition

LAN stands for Local Area Network. It connects devices within a small geographical area.

### Explanation

LAN aisa network hai jo chhoti jagah par devices ko connect karta hai, jaise ghar, office, school ya computer lab.

### Examples of LAN

- Home Wi-Fi network.
- School computer lab.
- Office ka local network.

### Advantages of LAN

- Files share karna asaan hota hai.
- Printers share kiye ja sakte hain.
- Local communication fast ho sakti hai.
- Resources share karne se cost kam ho sakti hai.

### Disadvantages of LAN

- Network setup aur maintenance ki zaroorat hoti hai.
- Security ka khayal rakhna parta hai.
- Network device kharab hone se communication affect ho sakti hai.

## 6. What Is WAN?

### Definition

WAN stands for Wide Area Network. It connects networks over a large geographical area.

### Explanation

WAN aisa network hai jo mukhtalif cities, countries ya bohat door ke locations mein mojood networks ko connect kar sakta hai.

### Examples of WAN

- Internet.
- Different cities mein branches ko connect karne wala company network.
- Bank ki mukhtalif branches ka connected network.

### Advantages of WAN

- Door mojood networks ko connect karta hai.
- Different locations ke darmiyan data share kiya ja sakta hai.
- Companies apni branches ko connect kar sakti hain.

### Disadvantages of WAN

- Isay manage karna mushkil ho sakta hai.
- Setup aur maintenance mehngi ho sakti hai.
- Security aur data privacy ka khaas khayal rakhna parta hai.

## 7. Difference Between LAN and WAN

| LAN | WAN |
|---|---|
| Full form Local Area Network hai. | Full form Wide Area Network hai. |
| Chhoti geographical area cover karta hai. | Bari geographical area cover karta hai. |
| Ghar, office ya lab mein use hota hai. | Cities aur countries ke darmiyan use ho sakta hai. |
| Aam tor par organization ya ghar manage karta hai. | Mukhtalif organizations aur service providers manage kar sakte hain. |
| Example: Home network. | Example: Internet. |

## 8. Difference Between IP Address and Router

| IP Address | Router |
|---|---|
| Aik logical address hota hai. | Aik physical networking device hota hai. |
| Device ko network par identify karne mein madad karta hai. | Networks ke darmiyan data forward karta hai. |
| Example: `192.168.1.10` | Example: Home Wi-Fi router. |

## 9. Real-Life Example of Networking

Maan lein aapke ghar mein aik Wi-Fi router hai.

- Mobile Wi-Fi se connect hota hai.
- Laptop bhi usi Wi-Fi se connect hota hai.
- Router local devices ko network se connect karta hai.
- Router internet connection ke zariye data bahar ke networks tak forward karta hai.
- Har device ka local network mein apna IP address ho sakta hai.

Is tarah devices networking ke zariye internet use aur data exchange karte hain.

## 10. Important Networking Terms

- **Network:** Connected devices ka group.
- **Router:** Different networks ke darmiyan data forward karne wala device.
- **IP Address:** Network par device ko identify karne wala logical address.
- **LAN:** Chhoti geographical area ka network.
- **WAN:** Bari geographical area ko cover karne wala network.
- **Wi-Fi:** Wireless networking technology.
- **Protocol:** Communication ke rules.
- **ISP:** Internet Service Provider jo internet connection provide karta hai.
